# Self-hosted font licenses

The files in this directory are the Latin web subsets currently used by the
site. They are served locally rather than from Google's font CDN.

- **Raleway** — SIL Open Font License 1.1. Source and license:
  <https://github.com/google/fonts/tree/main/ofl/raleway>
- **Karla** — SIL Open Font License 1.1. Source and license:
  <https://github.com/google/fonts/tree/main/ofl/karla>
- **Lora** — SIL Open Font License 1.1. Source and license:
  <https://github.com/google/fonts/tree/main/ofl/lora>

The font files are unmodified Google Fonts webfont subsets. No other font
licenses are implied by this directory.
